[INFERENCE] This is an upstream generic amd64, old-glibc candidate, rather
than a locally built -march=native helper. Neither ELF architecture, absent
GNU ISA properties, low glibc symbol versions nor executing --version proves
x86-64-v1 instruction compatibility on every code path. No baseline CPU
emulator, complete instruction audit or older-machine execution was done.
Do not describe the helper as independently proven baseline-CPU portable.

Release build-script evidence
-----------------------------
The upstream webpage links https://github.com/arx/ArxPackages as its packaging
scripts. Release revision 748ed8670fcb132242c237ca23c7aadc006a9711 is dated
2020-08-09 and titled "innoextract: Release version 1.9".
Inspected that release-record revision via its GitHub snapshot. No blanket
redistribution license for the packaging repository was located, so the
downloaded script snapshot is not retained or redistributed here. Original
Inno Setup test executables and unrelated project payloads are not included.
Recipe facts below refer to the named revision's original source at:
  https://github.com/arx/ArxPackages/tree/748ed8670fcb132242c237ca23c7aadc006a9711
No packaging scripts were executed.

innoextract/config requests USE_STATIC_LIBS=1 and USE_DYNAMIC_UTIMENSAT=1;
innoextract/config.linux selects amd64 and WITH_CONV=iconv. Root config selects
x86_64-bindist-linux-gnu and a glibc maximum of 2.6. Common scripts retain the
source-to-license inventory and allowlisted system-library rules. The verified
innoextract source CMakeLists.txt adds -static-libstdc++ and -static-libgcc for
USE_STATIC_LIBS. The observed ELF and bundled notices are consistent with
statically included Boost, zlib, libbzip2, liblzma and GCC runtime, while system
glibc/iconv remain dynamic. No statically linked ordinary LGPL component was
identified, so no LGPL relink-object obligation was identified for this helper.
The GPL GCC runtime carries its explicit exception as described above.

The recipe does not establish the exact build-time checkout or reproduce the
historical external toolchain/sysroot. The generic amd64 target and lack of
-march=native in the inspected configs do not prove the instruction baseline
of every prebuilt dependency or the resulting binary.
