IKV native Windows client and launcher — packaging notice
==========================================================

tools/package_windows.py cross-builds the IKV client and launcher from this source tree in the pinned container
tools/windows/Dockerfile (Debian 13 snapshot 20261007T000000Z, MinGW-w64 GCC 14 posix/SEH/msvcrt). It produces the
Setup.exe (NSIS) and the portable .zip. The package contains no original game data, installer, artwork or credentials:
the launcher imports the original files only from the user's own installer or installation folder. The icon is generic
packaging artwork. Every downloaded input is SHA-256 pinned in tools/windows/Dockerfile.

LGPL / GPL notes and source offer
  Qt is used unmodified and dynamically linked. To use a modified or different build of Qt (ABI-compatible MinGW
  6.11.x), replace the Qt6*.dll files and the plugin DLLs in bin\ of the installed or unpacked program; the IKV
  executables load them from that folder. The GCC runtime DLLs are covered by the GCC Runtime Library Exception.
  The project maintainers will also provide the corresponding sources of the LGPL/GPL components on request through
