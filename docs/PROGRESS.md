# Native reconstruction progress — 2026-10-08

## 2026-10-09 user playtest: completion claim retracted

A real user session on the dev stack showed the client does **not** resemble the original game: the Source0 spawn `[0,0]` sits on the sea, the camera ends up among dark geometry with no visible player, untextured helper boxes are drawn, the scene is far darker than daylight reference footage, and the screen is covered by debug HUD buttons and diagnostics (`analysis/user-report-1/gl-wayland.png`, `gl-top.png`). The launcher was reported as too complicated. Reference: original-game gameplay VOD frames under `analysis/reference-video/` (local only, not redistributed). Criteria 2, 3, 4 and 6 below are therefore **not met** regardless of the earlier scoped proofs; remediation (spawn/camera/helper geometry/lighting, original-style HUD, simplified launcher) is in progress. Earlier passes proved narrower properties than visual/playable parity.

**Remediation landed (same day):** root cause of the "overlapping" world was inverted front-face winding (GL_CCW / VK CCW vs D3D-clockwise source triangles): exterior surfaces were culled, so interiors appeared as gray boxes and actors inside-out. Now GL_CW / VK clockwise. Daylight environment values (ambient 1.0, directional 100/255, lightmap 80/255, sky-coloured fog 300..1200) replace the constructor baseline; they are **NONCANONICAL**, tuned against the reference VOD because the live environment record is unrecovered. Spawn moved to the Yeni Cami courtyard `[386000,806000]`, gameplay distances rescaled to the 1000-units-per-metre visual scale, camera default pitch .55/distance 22 with a nocamera-collider occlusion clamp. HUD rebuilt from the original UI1/UI2 atlases (player/target frames, Mesajlaşma chat, action bar 1..0, toggled windows; diagnostics to stderr). Launcher reduced to install → login → character → OYNA with a settings dialog. Real RX7900XTX GL/Vulkan captures `analysis/user-report-1/after-{opengl,vulkan}.png`; FULL/GL-only/SAN 14/14 each (42/42). Remaining visible gaps vs reference: colder/greyer palette than the warm sunlit original, no minimap, no dynamic shadows of actors, particle member absent.

**Second playtest fixes:** (1) Questgiver and merchant shared `source_uid` 1001 (Agah); merchant is now 1002 Agop, and the server fills per-kind defaults once at load (enemy 16001/9, merchant 1002/17, questgiver 1001/16). The 373 classes.dat npc/monster records are listed in `analysis/user-report-2/npcmodels/npc-records.json`; 1004/1008/1013/1015 fail to assemble because of original-data biped or binding mismatches. (2) Actors walked backwards: source models face local −Z, so the heading is now `atan2(old−new)`. (3) The run cycle snapped to idle about once per second: original 0047bea0 gives looping clips an effectively infinite jump deadline, so the new `ActorAnimation::action_held` suppresses the timed jump for looping actions set by `set_actor_action`. Evidence is in `analysis/user-report-2/{npcmodels,walkfacing}/`.
