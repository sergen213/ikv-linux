# Annotated original function map

## Scope and confidence

Addresses below are preferred **virtual addresses**, not file offsets or runtime observations. Game entries refer to statically UPX-decompressed `analysis/unpacked/istanbul.exe`, image base `0x00400000`, SHA256 `44ffa8389a9f6e4c35841103ad4f40a90513e4deb518ab5605b0a1ebfae0be2d`. Original packed `original/app/istanbul.exe` hash is `bff4cffe753a04e237e3ed32c3798eda10a602d73424a2b228024762da44aba6`. Launcher entries refer to original `launcher.exe` (same base), hash `096a9fa7c3bd701d5b486fee9862786b8c0a4cacbc0656250910364e10890e2e`.

**C-static**: directly observed calls/data flow. **I**: descriptive reconstruction. **U**: unassigned/unrecovered. These are analyst names, not recovered debug symbols. Parameters are conservative logical roles; exact class layouts, calling conventions and signedness are not established unless stated. Ghidra inferred `__fastcall`/`__thiscall` frequently reflects an object in ECX with incomplete type information, not an independently validated source prototype. Winsock annotations model x86 stdcall argument footprints, not complete SDK structures.

All local decompilation stays ignored under `analysis/`; documentation distributes addresses, observations and independent summaries only. Reproduction and metadata: [REVERSE_ENGINEERING](REVERSE_ENGINEERING.md). Full relevant caller/signature lists are in each evidence directory's `functions.tsv` and `imports.tsv`.

## Explicit gaps

No function is claimed here as a validated original combat, movement, inventory, quest, NPC, account or zone-handoff implementation. Camera controls, meshes/skeleton transforms, animation, authoritative world rules and all handler schemas require further bounded evidence. Existing native movement/snapshots are custom demonstration semantics. Ghidra decompilation has incomplete type information, occasional false no-return propagation and indirect-call ambiguity; use the saved project/disassembly when extending evidence instead of translating generated C literally.
