**Legend**
- **Recov.** (recoverable): **yes** = the original client data or code defines it; **partial** = the client holds UI, strings or data, but the rules lived on the official server; **server-only** = nothing in the client defines it.
- **Status**: **ported** = faithful to original data or code (server-only numbers may still be NONCANONICAL, as noted); **partial** = some original behaviour present; **noncanonical** = the mechanism itself is an invented, config-driven rule (`config/gameplay.json` provenance keys); **missing** = nothing exists; **n/a** = not an original feature.
- **Pri**: **P0** visible in the first minutes of play; **P1** core loop within the first hour; **P2** later content or polish.

## 3. Notes

- The native JSON application protocol (message types, state fields including catalogs-on-change, actions, validation limits) is documented in [`docs/network/CUSTOM_PROTOCOL.md`](network/CUSTOM_PROTOCOL.md).
- Chat, quest, gathering and death texts seen in the VOD (e.g. "Salgın hastalık", "toplayabilmek için") are **not** in the exe. They were server-sent, so their wording and objectives are server-only, and any native version is NONCANONICAL.
- Client-side numbers now used: vendor sell divisor 5, the 4-characters-per-account limit, the 4-16 letter name rule, the 15 s resurrect deadline, the 1000 ms global cooldown. Still unused: the Plus divisor 3 and the 999 million currency caps.
- No cast bar, mount, weather trigger or minimap draw function has been located; the minimap's existence is VOD-proven. Cast bars were not seen in the VOD; instant skills are consistent with that [INFERENCE]. Cast clips were server-sent (`mink` `004a4270`); the native per-skill cast clip (57 area/self, 51 enemy, 53 ally, Savaşçı Double_*/swing) is NONCANONICAL apart from clip 57, which matches VOD 14:52.
- Robustness fixed in wave 2-3: a client no longer exits when an actor fails to assemble (one stderr line, label only); the server sends `catalogs` only on admission and change and the client judges read deadlines after `poll()`, which fixed the first-connection timeout (`analysis/porting-wave3/Polish2/stall-after.json`, regression `tests/client_eof.py` stalled_native); Vulkan original lighting guards zero tangents (dot-grid artifact).
- Robustness fixed in wave 4: an actor entering or leaving the AOI no longer re-uploads the whole zone. The old cost was Vulkan 2.4–3.4 s, RT 8–25 s and GL ~0.43 s per event, and a monster patrolling across the AOI edge repeated it 31 times in 104 s. Actor meshes are keyed and the GL, Vulkan and RT providers keep the GPU resources of everything that did not change. See [`GRAPHICS_ROADMAP.md`](GRAPHICS_ROADMAP.md) and `analysis/porting-wave4/Stall/summary.json`.
